# ДВОЙНОЙ ВПР

## Формула

```excel
=ЕСЛИОШИБКА(ИНДЕКС($J$35:$T$3000;ПОИСКПОЗ(Z33;$J$35:$J$3000;0)+AA33-1;3);"")
```

## Назначение

Формула находит строку по значению из ячейки `Z33`, затем применяет смещение строки из `AA33` и возвращает значение из заданного столбца массива.

## Параметры

- Массив: `$J$35:$T$3000`
- Столбец поиска: `$J$35:$J$3000`
- Искомое значение: `Z33`
- Смещение строки: `AA33-1`
- Номер возвращаемого столбца массива: `3`
- При ошибке возвращается пустая строка

## Комментарий

После выражения `+AA33-1` указывается номер столбца массива, из которого необходимо вернуть значение.

В данном случае число `3` означает выбор значения из третьего столбца массива `$J$35:$T$3000`, то есть из столбца `L`.

`AA33-1` определяет смещение строки, а `3` определяет номер столбца выбора внутри массива.
