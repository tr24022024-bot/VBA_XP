# LEFT + MID — извлечение частей строки и сложение

## Формула 1

```excel
=LEFT(Sheet1!B25;2)+MID(Sheet1!B25;4;3)
```

## Логика

- `LEFT(Sheet1!B25;2)` — берёт первые 2 символа из `Sheet1!B25`.
- `MID(Sheet1!B25;4;3)` — берёт 3 символа, начиная с 4-го символа.
- Оператор `+` преобразует полученные числовые фрагменты в числа и складывает их.

### Пример

Если `Sheet1!B25 = "12-345"`, то:

- `LEFT(...;2)` → `12`
- `MID(...;4;3)` → `345`
- результат → `357`

> Если извлечённые фрагменты не являются числами, Excel вернёт ошибку `#VALUE!`.

---

## Формула 2 — выборка относительно конца строки

```excel
=MID(Sheet1!B25;LEN(Sheet1!B25)-5+1;2)+MID(Sheet1!B25;LEN(Sheet1!B25)-2+1;2)
```

## Логика

- `LEN(Sheet1!B25)` — определяет общую длину строки.
- `MID(Sheet1!B25;LEN(Sheet1!B25)-5+1;2)` — берёт 2 символа, начиная с позиции, вычисленной относительно 5-го символа справа.
- `MID(Sheet1!B25;LEN(Sheet1!B25)-2+1;2)` — берёт последние 2 символа.
- Оператор `+` складывает оба извлечённых числовых фрагмента.

> Формула удобна, когда длина исходной строки может меняться, а нужные значения должны извлекаться по позициям справа.

# LEFT / MID / LEN / RIGHT — выбор символов по позиции

## 1. Первые N символов слева

Первые 5 символов из `A1`:

```excel
=LEFT(A1;5)
```

В Excel с запятой как разделителем аргументов:

```excel
=LEFT(A1,5)
```

## 2. Один символ по номеру позиции слева

3-й символ из `A1`:

```excel
=MID(A1;3;1)
```

В Excel с запятой:

```excel
=MID(A1,3,1)
```

Русское имя функции:

```excel
=ПСТР(A1;3;1)
```

## 3. Один символ по динамическому номеру позиции

Если в `B1` записан номер нужного символа:

```excel
=MID(A1;B1;1)
```

В Excel с запятой:

```excel
=MID(A1,B1,1)
```

## 4. Один символ по счёту справа

3-й символ справа:

```excel
=MID(A1;LEN(A1)-3+1;1)
```

В Excel с запятой:

```excel
=MID(A1,LEN(A1)-3+1,1)
```

Общий принцип:

```excel
=MID(ячейка;LEN(ячейка)-номер_справа+1;1)
```

## 5. Динамический номер позиции справа

Если `B1` содержит номер символа при счёте справа:

```excel
=MID(A1;LEN(A1)-B1+1;1)
```

В Excel с запятой:

```excel
=MID(A1,LEN(A1)-B1+1,1)
```

## 6. Последний символ

Последний символ из `A1`:

```excel
=RIGHT(A1;1)
```

В Excel с запятой:

```excel
=RIGHT(A1,1)
```

Русское имя функции:

```excel
=ПРАВСИМВ(A1;1)
```

## Английские имена используемых функций

- `ЛЕВСИМВ` → `LEFT`
- `ПСТР` → `MID`
- `ДЛСТР` → `LEN`
- `ПРАВСИМВ` → `RIGHT`
