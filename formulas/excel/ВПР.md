# ВПР

## Формула

```excel
=ВПР(A1;D5:P20;2;0)
```

## Назначение

Формула ищет значение из ячейки `A1` в первом столбце массива `D5:P20` и возвращает значение из второго столбца найденной строки.

## Параметры

- Искомое значение: `A1`
- Массив поиска: `D5:P20`
- Номер возвращаемого столбца: `2`
- Тип совпадения: `0` — точное совпадение
